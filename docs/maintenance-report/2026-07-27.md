## Code Quality — HTML correctness fixes

Ran the site's two HTML pages through the W3C-based `html5validator` (Nu Html Checker) and fixed every real structural defect found:

- **`404.html`**: `<style>` block was placed *before* `<head>`, then a second `<head>` was opened afterwards (invalid duplicate `<head>`). Moved `<style>` inside the single `<head>` element.
- **`index.html`**: the hero `<section>` carried a stray `alt` attribute (not valid on `<section>`, and unused since the background image is applied via a JS parallax plugin, not an `<img>`). Removed it.
- **`index.html`**: a `<div class="flipletter">`/`<div class="movingletter2">` were nested inside `<h3>`/`<h1>` respectively, which only permit phrasing (inline) content. Changed both to `<span>` and added `display: block` to their existing CSS rules (`Content/WordAnimation/flip-shake-flick-buzz.css`, `Content/WordAnimation/movingletter.css`) so the rendered box model is unchanged.
- **`index.html`**: the `#projects` section opened a `<div data-aos="zoom-in">` wrapper that was never closed, leaving the whole projects section with an unbalanced element tree (a real bug — browsers silently error-correct this, but it made the rest of the document's structure unpredictable). Added the missing closing `</div>`.

After these fixes, both pages pass HTML validation cleanly (one benign, pre-existing `<ul>`-inside-heading pattern from the original template is intentionally ignored by the CI check — restructuring it would touch the greeting flip-animation's JS/DOM contract for no functional benefit).

Verified via a local static-file server + headless Chromium screenshot that the page still renders (layout identical to the pre-fix version; the offline sandbox can't reach Google Fonts/CDN assets, so both before/after screenshots render the same "assets unavailable" state — confirming the fix didn't change anything render-relevant).

No other refactoring was performed — the rest of the codebase (vendored assets, custom scripts for greetings/experience calculation/Scribbler) was left untouched per the "smallest safe change" principle.
