## CI/CD

Added `.github/workflows/ci.yml`, the repository's first CI pipeline, running on every push and pull request against `main`:
- **HTML validation** (`Cyb3r-Jak3/html5validator-action`) over `index.html`/`404.html`, excluding the vendored `Content/` directory.
- **Broken link checking** (`lycheeverse/lychee-action`) over the same two pages, excluding `mailto:`/`tel:` links and known bot-blocking third-party domains (`linkedin.com`, `reddit.com`) and the Formspree form endpoint, to avoid false-positive CI failures from external services rather than real repository issues.

Both jobs must pass for a pull request to be considered green.
