**Upgrade decision — Bootstrap 4.6.0 → 4.6.2: not applied.** Diffing the two CSS files shows the 4.6.x changes are `.small`/`small` and form-feedback `font-size` (80% → .875em), form-validation padding tweaks, and a Firefox `select` focus-ring rule. `404.html` uses none of the affected selectors (`small`, `blockquote-footer`, `form-control`, validation classes, `select`), and `index.html` doesn't load Bootstrap at all (checked: no Bootstrap in the Hola CSS bundle, no Bootstrap references in any vendored JS), so the bump would have no visible effect there and no security benefit (CVE-2024-6531 remains unpatched on the 4.x line regardless). Not worth the churn; revisit only if the 404 page starts using form or `small` markup. jQuery 4.0.0 and Bootstrap 5 remain deliberately deferred — no security driver, both are non-trivial breaking upgrades.
